# Embedded Systems Lab

A collection of Embedded Systems laboratory programs, Keil µVision projects, Proteus simulations, and compiled outputs developed using the **LPC2138 ARM7 microcontroller**.

## Contents

Each laboratory folder contains relevant:

- Embedded C source programs
- Keil µVision project files
- Startup assembly files
- Proteus simulation files
- Compiled HEX files
- Build and listing files

## Tools & Technologies

- **Microcontroller:** LPC2138 ARM7
- **IDE:** Keil µVision
- **Simulation:** Proteus
- **Programming:** Embedded C, ARM Assembly
- **Version Control:** Git & GitHub

## Purpose

This repository serves as a structured collection of Embedded Systems laboratory work, including source code, project files, simulations, and compiled outputs for reference and academic use.
